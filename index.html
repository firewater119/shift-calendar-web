근무 유형

‘색상표’를 열고 색을 누르면 달력·팀별·통계에 바로 적용됩니다. 색상표 아래 ‘직접 고르기’에서는 밝기·채도 판과 색상 막대로 원하는 색을 직접 만들 수 있습니다. ‘기본 색으로’를 누르면 그 유형의 원래 색으로 돌아갑니다. 행 오른쪽의 작은 ×를 누르면 그 유형을 사용하지 않습니다. 사용 안 함으로 바꾼 유형은 ‘사용하기’를 눌러 다시 쓸 수 있습니다.

바로가기 추가 방법

  1. 안드로이드: 카톡에서 열었다면 오른쪽 위 ⋯ → 다른 브라우저로 열기로 크롬에서 엽니다.
  2. 크롬 오른쪽 위 ⋮ 메뉴 → 홈 화면에 추가를 누릅니다.
  3. 아이폰: 링크를 Safari로 열기 한 뒤 하단 공유 버튼 → 홈 화면에 추가 → 추가를 누릅니다.
  4. 홈 화면의 교대달력 아이콘으로 바로 열 수 있습니다. 바로가기로 열면 전체화면으로 보입니다.

이미 뮤즈 아이콘으로 추가된 바로가기가 있으면 아이콘이 자동으로 바뀌지 않습니다. 그 바로가기를 지우고, 크롬에서 다시 추가하면 달력 아이콘으로 생깁니다.
