# 교대달력 웹 버전 (Shift Calendar Web)

소방관 교대근무 달력 웹 앱. 아이폰·안드로이드 브라우저에서 사용한다.
달력·팀별·통계·설정, 메모·일정, 근무패턴 편집, 백업 내보내기/가져오기를 지원한다.

버전: v1.0.35

## 사용법

- `index.html`을 브라우저로 연다. (별도 빌드 과정 없음)
- 데이터(근무패턴·메모·일정·색상)는 브라우저 localStorage에 저장된다. 기기·브라우저마다 따로 저장되므로, 바꾸면 백업 파일로 옮겨야 한다.
- 아이폰: Safari로 열고 공유 → 홈 화면에 추가로 바로가기를 만들면 앱처럼 쓸 수 있다.

## 참고

- 이 저장소는 소스 보관용 비공개 저장소다. 안드로이드 앱(APK)은 별도 저장소(firewater119/shift-calendar-app)에서 배포한다.
- 알람 기능은 없다.
